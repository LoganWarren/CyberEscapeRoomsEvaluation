Frequently Asked Questions

  • Do I need special hardware?
    Most rooms can be played with a laptop and internet connection. If a room needs extra hardware, it’s listed on that room’s page.
  • How long does a game last?
    Typically 30–60 minutes depending on the group.
  • Can we host this for a class?
    Yes. See each room’s “How to Play / Set Up” section for facilitation tips and materials.

Troubleshoot Guide

  1. Check your internet connection and try a hard refresh (Ctrl/Cmd + Shift + R).
  2. Follow the setup instructions on the room’s page (browser, resolution, required files).
  3. If problems persist, open an issue in the GitHub repo (include room name, steps to reproduce, and screenshots if possible).
