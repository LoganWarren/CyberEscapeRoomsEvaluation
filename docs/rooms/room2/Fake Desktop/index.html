Enter Password

Hints to discover the password:

  • 1. You first want to unlock the lock box using the materials in the briefcase. Using the cards and the card reader, you want to place each card in the card reader looking for a colored arrow in one opening and a number in the second opening. Use this color and number correspondence to discover the combination of the lockbox's lock.

  • 2. After you have opened the lockbox, you will need to traverse the Ceasar Cipher maze. As you go through the maze keep track of (it is reccomended that you write down) the letters as you find them.

  • 3. You should now have finished the maze and have a string of seemingly random characters. The key is the numerical shift of your Ceasar Cipher. Use the Ceasar Cipher information page and tool to decrypt this string.

  • 4. Once you have decrypted the string, use the flashlight and the song lyric sheets to match your message to the attackers desktop password.
