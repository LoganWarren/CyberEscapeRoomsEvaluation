Walkthrough for Facilitators

  1. Begin by printing every document from the Resources page. Arrange all materials at the workstation before the session begins to ensure a smooth start.
  2. Sign in to each employee account using the information on the ID cards. Jaime’s username is j.graves2 with the password CavsFan123. Sam’s username is s.carters7 with the password smokedsalmon24.
  3. Once logged in, open each inbox and look for anything that seems out of place. Messages from the sender sreniram66 are especially important, along with emails titled Quick Access Check or A New Transaction. Sam’s inbox contains an unusual conversation, while Jaime’s inbox includes an entire folder dedicated to suspicious content.
  4. Inside Jaime’s suspicious folder, find the email describing a questionable transaction. It includes an external conversation, an IP address, and a hashed set of credentials connected to an FTP server.
  5. Use an MD5 decryption tool to convert the hashed credentials into readable values. The correct FTP login information reveals itself as follows. The host is 73.118.209.254, the username is carters, and the password is seahawks.
  6. Connect to the FTP server using these details. Three stolen files will appear, each referencing Sam. These files match the locked PDFs inside Sam’s file explorer.
  7. Open each locked file on Sam’s computer. Every file includes a brief password hint, and the answers can be found using OSINT or the physical desk items. The password for clientDatabase.pdf is hansen, which is the last name of Sam’s best friend mentioned in a company social post. The password for employeeInformation.pdf is cruze, the model of Sam’s first car shown on his parking permit. The password for productRoadmap.pdf is seattle, which appears in several clues throughout the game, including the username sreniram66 which spells mariners backward.
  8. After entering all three passwords, players receive the final prompt and are directed to complete a short incident report. A template and an example are available in the Resources section.
  9. All puzzle answers use lowercase letters without spaces. It helps to keep printed backups of the employee cards, the parking pass, and the social post images to make resetting the room easier.
