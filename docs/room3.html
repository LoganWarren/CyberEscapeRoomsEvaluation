About This Room

Room 3 is meant to teach the players core cybersecurity concepts, such as using Open Source Inteligence, Encryption, Decryption, how to file an Incident Response Report, and how to pick up on phishing attempts and other human-factor vulnerabilities.

How to Play / Set Up

  • Make sure your screen resolution is at least 1280×720.
  • Have a scratchpad available for artifact notes & timestamps.
  • Print out all materials needed for the room included in the files below.
